# Notebooks

This folder contains Jupyter notebooks for interactive exploration and visualization during development.

## Contents

- `ssl_transforms.ipynb`  
  Demonstrates and visualizes the SSL data preprocessing pipeline, including:
  - Building data loaders for narrowband and wideband datasets
  - Applying and visualizing data augmentations (BYOL, DenseCL, DINO, MoCo)
  - Inspecting time masks and feature vectors for narrowband samples
  - Visualizing spectrograms, IQ signals, and time-domain masks
