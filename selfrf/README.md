# selfrf

Core source code for the RF signal representation learning framework.

This folder contains all project components, including models, data pipelines, transforms, utilities, and training logic.

## Structure

- `data` — Custom dataset classes
- `finetuning` — Downstream fine-tuning pipelines *(if applicable)*
- `models` — Model architectures (IQ models, metadata towers, SSL models, fusion heads)
- `pretraining` — SSL training logic, configuration, dataset factories
- `transforms` — Data augmentation pipelines
- `utils` — Visualization tools and general utilities

## More Information

Each subfolder contains its own `README.md` with detailed explanations of its purpose and structure.
