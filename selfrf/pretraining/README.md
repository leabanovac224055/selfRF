# Pretraining Package

This package contains all modules related to the self-supervised learning (SSL) and multi-modal pretraining framework.

### Structure

- **config/**: Centralized configuration system for training and evaluation.
- **evaluation/**: t-SNE and KNN-based representation evaluation tools.
- **factories/**: Modular builders for models, transforms, dataloaders, etc.
- **utils/**: Utility functions and callbacks for model training.

This structure enables flexible experimentation with SSL models, metadata towers, and fusion architectures for RF signal processing.
