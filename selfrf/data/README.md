# 📁 Data Folder Overview

This folder contains all components related to data preparation, loading, and integration for narrowband IQ signal learning, metadata tower and two-tower model training.

---

## 🗂️ Folder Structure

| Folder   | Description                                               |
|----------|-----------------------------------------------------------|
| `iqdm/`  | Narrowband preprocessing scripts and IQ dataset definitions. |
| `meta/`  | Metadata tower, metadata preprocessing, and two-tower dataset utilities. |
| `fusion/`| Fusion head and two-tower model training modules.         |

---

## 🛠️ Notes

- See individual folder `README.md` files for detailed descriptions.  
- Assumes narrowband `.zarr` data and extracted metadata are generated via preprocessing pipelines.
