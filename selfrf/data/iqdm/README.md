
# 📁 Narrowband Data Preprocessing Scripts & IQ Dataset Loader

This folder contains:

✅ Scripts for preprocessing **SigMF** recordings into **TorchSig-compatible Zarr datasets**, ready for machine learning tasks.  
✅ A custom **IQ dataset and PyTorch Lightning DataModule** for easily loading preprocessed `.zarr` narrowband data into training pipelines.

The focus is on narrowband signal extraction, realistic signal isolation, and preparation, as well as providing dataset logic compatible with TorchSig and PyTorch Lightning. Older versions and experimental scripts are also included for reference.

## 🛠️ Recommended Preprocessing Pipeline

### ✅ `narrowband_final.py`

This script converts SigMF `.meta` and `.data` files to a TorchSig-compatible `.zarr` format with realistic signal isolation and noise injection:

- **Time and frequency isolation** of annotated signals.
- Computes signal power and boosts it to a target level.
- Injects signals into a noise background with controlled SNR.
- Saves preprocessed signals to `.zarr`.
- Saves normalized feature vectors to `feature_vectors.json`.

No additional feature extraction step is needed after running this script.

---

## 🧮 Metadata Normalization (Tower B Inputs)

The metadata feature vectors stored in `feature_vectors.json` follow this normalization:

- **Center Frequency** → divided by 1e9 (stored in GHz).
- **Bandwidth** → `log10(bandwidth + 1)` to compress dynamic range.
- **Duration** → `log10(duration + 1e-6)` to handle skewed distributions and avoid log(0).

## 🧰 Working with Existing `.zarr` Datasets

If you already have a `.zarr` dataset (e.g., generated by TorchSig tools) that does **not** include feature vectors, you can extract them using:

```bash
python extract_meta_from_zarr.py
```

This generates a `feature_vectors.json` file containing normalized metadata suitable for use in metadata towers or multi-modal learning pipelines.

## 🧠 IQ Dataset for Model Training (`iq_dataset.py`)

This script provides the dataset logic and Lightning DataModule for loading `.zarr` narrowband data during training:

- **`ZarrNarrowbandDataset`**:
  - Loads preprocessed `.zarr` narrowband data.
  - Supports TorchSig's `DatasetSignal` structure.
  - Automatically reconstructs **time masks**, marking the signal region within each frame.
  - Supports flexible metadata target extraction for tasks like classification or metadata towers.

- **`IQDMNarrowbandDataModule`**:
  - Handles reproducible train/validation splits.
  - Integrates TorchSig-style collate functions.
  - Simplifies data loading within PyTorch Lightning pipelines.

⚠️ The script also contains wideband dataset logic, but wideband functionality is currently outdated and **not actively maintained**.

---

## 🚀 Example Preprocessing and Training Workflow

1. **Preprocess raw SigMF files**:

```bash
python narrowband_final.py
```

This generates:

- `datasets/NARROWBAND_ZARR/data.zarr` — preprocessed signal data.
- `datasets/NARROWBAND_ZARR/feature_vectors.json` — normalized metadata for model inputs.

2. **Train your model using `iq_dataset.py` with the generated `.zarr` dataset**.
