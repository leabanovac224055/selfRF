
# 📁 Metadata Tower & Two-Tower Dataset Utilities

This folder contains tools and dataset definitions for preparing and handling **metadata feature vectors**, training a **metadata tower**, and loading combined IQ and metadata inputs for **two-tower learning pipelines**.

The scripts here are designed to:

- ✅ Preprocess and scale metadata feature vectors.  
- ✅ Provide a self-supervised training module for learning metadata embeddings.  
- ✅ Define a PyTorch Dataset and LightningDataModule for combined IQ and metadata inputs (two-tower models).  

---

## 🗂️ Folder Contents

| File                      | Description                                                                 |
|---------------------------|-----------------------------------------------------------------------------|
| `data_standard_scaler.py` | Fits a StandardScaler to normalized metadata feature vectors and saves the scaler for consistent training and deployment. Optionally saves scaled feature vectors for dataset loading. |
| `meta_tower.py`           | Defines a self-supervised LightningModule for metadata-only contrastive learning using NT-Xent loss. Includes simple metadata augmentation. |
| `two_tower_dataset.py`    | Provides a PyTorch Dataset and LightningDataModule for combined IQ and metadata input, supporting two-tower learning pipelines. |

---

## 🧮 Metadata Preparation (`data_standard_scaler.py`)

This script fits a `StandardScaler` to normalized metadata feature vectors, ensuring consistent scaling for both training and deployment of metadata towers.

**Features:**

- Loads `feature_vectors.json` generated during narrowband preprocessing.
- Extracts center frequency (GHz), bandwidth (log-scaled), and duration (log-scaled).
- Fits a `StandardScaler` to the feature vectors.
- Saves the fitted scaler to `metadata_scaler.pkl`.
- Optionally saves scaled feature vectors to `X_scaled.npy` for use with `TwoTowerDataset`.

**Example:**

```bash
python data_standard_scaler.py
```

---

## 🧠 Metadata Tower Self-Supervised Module (`meta_tower.py`)

Implements a self-supervised learning module for metadata vectors using NT-Xent contrastive loss.

**Key components:**

- `augment_metadata`: Adds small Gaussian noise for augmentation.
- `NTXentLoss`: Contrastive loss promoting similarity between positive pairs.
- `MetadataTrainModule`: PyTorch Lightning module for metadata-only representation learning.

---

## 🔀 Two-Tower Dataset and DataModule (`two_tower_dataset.py`)

Provides:

### `TwoTowerDataset`

- Loads both IQ data (`.zarr`) and scaled metadata feature vectors (`X_scaled.npy`).
- Supports flexible training stages: IQ-only, metadata-only, or full two-tower setups.
- Reconstructs time masks marking signal regions within IQ frames.

### `TwoTowerDataModule`

- Handles dataset splits, transforms, and collate functions.
- Provides DataLoaders for combined IQ and metadata input pipelines.
- Fully compatible with TorchSig-style IQ data and custom metadata inputs.

---

## 🛠️ Notes

- Requires narrowband `.zarr` data and `feature_vectors.json` generated by preprocessing pipelines.
- Requires scaled feature vectors (`X_scaled.npy`) generated by `data_standard_scaler.py`.
- Expects IQ samples and metadata vectors to be properly synchronized.
